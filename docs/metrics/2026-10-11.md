# Metrics snapshot — 2026-10-11

**What this is:** the measurements [`docs/metrics.md`](../metrics.md) describes,
read once on 2026-10-11 at `main` = `550ad80`. Each table below is what the
command beside it printed that day. Every command is scoped to a fixed range
(pull requests up to #78, workflow runs created before 2026-10-11), so
rerunning it later asks about the same pull requests and runs, and each names
`Danathar/zfs-aurora-complex` so it reads this repository whatever the clone's
remotes are.

A rerun can still print different numbers, because the range fixes *which*
items are read, not what GitHub says about them later: a pull request can be
reopened, a review comment can be added or deleted, a workflow run can be
re-run, and GitHub deletes old run logs. Where a rerun disagrees with a table,
the table is the reading from 2026-10-11 and the rerun is the current state.
For current values, run the commands in `docs/metrics.md`. Leave this file as it
was read.

`docs/metrics.md`'s warnings apply to every number here, and its section "What is
deliberately not measured" says which numbers were left out on purpose. Read both
before quoting anything below.
